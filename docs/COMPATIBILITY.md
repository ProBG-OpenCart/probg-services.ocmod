# Compatibility

## OpenCart 3

Target range:
- 3.0.2.x
- 3.0.3.x

Implementation:
- MVC-L extension structure
- Twig templates
- OCMOD only where core integration cannot be achieved through events
- Compatibility with standard OpenCart 3 administration

## OpenCart 4

Target range will be fixed after verification against the maintained OpenCart 4 releases at implementation time.

Implementation:
- Namespaced extension structure
- OpenCart 4 installer/package format
- Event-based integration
- Bootstrap 5 compatible administration UI

## PHP

Supported PHP versions will follow each supported OpenCart branch and will be documented and tested per release package.
